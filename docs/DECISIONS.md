# Решения, принятые при реализации ТЗ Iter Meum v2

Файл ведётся по правилу агента из раздела 14 ТЗ: любая зависимость сверх
списка и любое отступление от буквы ТЗ фиксируются здесь.

| № | Решение | Почему |
| --- | --- | --- |
| D-01 | Sentry удалён вместе со старым слоем. | Раздел 13: «нет аналитики и сторонних SDK, кроме Google Sign-In/Drive». |
| D-02 | У debug-сборки нет `applicationIdSuffix`. | Приложение ставится из APK (раздел 2); OAuth-клиент Google привязан к имени пакета `com.itermeum.app` — суффикс `.debug` сломал бы Sign-In для сборки, которую реально ставит пользователь. |
| D-03 | Зависимость `ui-text-google-fonts` удалена. | Раздел 13: 100 % оффлайн. Шрифты OFL (PT Serif, PT Serif Caption, Cormorant SC, JetBrains Mono) будут вшиты в `res/font` в фазе 9. Проверено: у всех четырёх есть кириллица, включая «Ё». |
| D-04 | Все фазы ведутся коммитами в одной ветке `claude/sleepy-curie-c5lhqh`, по одному коммиту-вехе на фазу. | Правила сессии запрещают пуш в другие ветки без явного разрешения; разбить на отдельные PR можно постфактум. |
| D-05 | Критерий фазы 1 `grep -ri "avangard\|Rand\|Sabotage" src/` трактуется как отсутствие ссылок на старый пакет, Айн Рэнд и Sabotage Protocol. | Регистронезависимый `Rand` ловит `SecureRandom`/`random`, которые нужны для AES-GCM IV (раздел 8, I6) и бэкапа. В коде старых смыслов нет. |
| D-06 | Растровые launcher-иконки не поставляются; только adaptive-icon из векторов (`mipmap-anydpi-v26`). | `minSdk 26` — adaptive icon поддерживается всеми целевыми устройствами. Форма по разделу 12: квадрат со срезанными углами, крест с расширяющимися концами, линия-дорога. |
| D-07 | Добавлены таблицы, которых нет в списке раздела 8: `morning_state` (автомат утреннего блока 5.1, одна строка на день), `jaculatoria_log` (отметки «произнёс» для правила «≥3 в день»), `rosary_progress` (прогресс декад «до 23:59, можно частями»), `monthly_summary_view` («экран просмотрен» для нормы `monthly_summary`). | Правила засчитывания из раздела 4 требуют этих данных; в разделе 8 для них не было сущностей. |
| D-08 | Лекционарий: ссылки с запятой могут начинать новый сегмент с номером главы (`Jn 15:26-27,16:12-15`); парсер `BibleReference` это принимает. Пятидесятница: A — Jn 20:19-23, B и C — годовые альтернативы. | Собственная сборка таблиц (11.2); формат расширен, чтобы не упрощать чтения. Все таблицы помечены `verify:true` до сверки с официальным ordo. |
| D-09 | Тексты молитв: базовая редакция — распространённые русские католические тексты; `verify:true` у всех, кроме крестного знамения, «Слава Отцу», краткого сокрушения и собственных текстов приложения. | Раздел 7.1: пользователь сверяет каждую молитву с тем, как молятся в соборе, и правит в настройках. |
| D-10 | Вознесение и Тело и Кровь Христовы по умолчанию переносятся на воскресенье (E+42, E+63); флаг `LiturgicalCalendar.transferToSunday` — настройка. | В России решением ККЕР эти торжества переносятся на воскресенье; открытый вопрос №4 ТЗ ставил по умолчанию четверг с флагом verify — флаг сохранён как настройка, по умолчанию выбран российский порядок. Подлежит сверке с ordo собора. |
| D-11 | Добавлены зависимости: `androidx.camera:*` 1.3.4 и `com.google.mlkit:barcode-scanning` 17.3.0 (сканирование QR, раздел 5.1 «камера + ML Kit Barcode оффлайн»), `com.google.zxing:core` 3.5.3 (генерация PNG QR-кода для кухни — ML Kit умеет только читать). | Требование ТЗ 5.1/13.5 (QR показать и сохранить PNG). Обе библиотеки работают без сети. |
| D-12 | Три звука будильника (`res/raw/bell_1..3.wav`) синтезированы (затухающие колокольные тона), а не записаны. | Раздел 5.17 требует «3 встроенных звука-колокола»; сторонних аудио-ассетов с ясной лицензией в репозитории нет. |
| D-13 | Экран «Зал» реализован карточкой на вкладке «Сегодня» (таймер «Выход через 10 минут» + кнопки «Зал» / «Домашняя тренировка 20 мин»), а не отдельным `GymCheckScreen`. | После «Serviam» телефон откладывается на 30 минут карантина; отдельный экран, который надо открыть вручную, никто не увидит. Карточка появляется сразу после ответа на вопрос о карантине. |
